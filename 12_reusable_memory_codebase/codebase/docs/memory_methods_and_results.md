# Memory methods and performance status

The [reference-method guide](reference_methods.md) defines LDMR scene memory,
the TR3D_OBJ-style object extension, and their UniDet3D adaptations.
The [validation report](unidet3d_validation.md) records current source and
real-data checks. Full-schedule accuracy for these named recipes is pending.

Scene and object bank counts measure different units. Compare memory bytes,
points replayed, natural-scene exposure, pseudo supervision, initialization and
optimization before attributing any difference to the bank representation.
No accuracy ranking is claimed for the current recipes.
